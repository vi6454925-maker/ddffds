### 4. СКО среднего
σ(h̄) = √(Σ(Δhᵢ)² / (n(n−1))) = √(0,0480 / 20) = √0,0024 = **0,049 мм**

### 5. Случайные погрешности (P = 0,95; t = 2,78)
Δh_сл = σ(h̄)·t = 0,049 · 2,78 = **0,136 мм**
Δd_сл = σ(d̄)·t = **0 мм**

### 6. Результирующие погрешности
Δs(h)/σ(h̄) = 0,1 / 0,049 = **2,04** → попадает в 0,8 … 8 → k = 0,71:
**Δ(h̄) = k·[Δs(h) + σ(h̄)·t] = 0,71·(0,1 + 0,136) = 0,17 мм**

Δs(d)/σ(d̄) = 0,1 / 0 = ∞ **> 8** → учитывается только систематическая:
**Δ(d̄) = Δs(d) = 0,10 мм**

### 7. Относительные погрешности
δ(h̄) = 0,17/39,98 · 100 % = **0,42 %**
δ(d̄) = 0,10/15,00 · 100 % = **0,67 %**
δ(m) = 0,01/19,07 · 100 % = **0,05 %**

# Упражнение 3. Погрешности косвенных измерений плотности

### 1. Среднее значение
ρ̄ = 4m / (π·h̄·d̄²) = 4·19,07 / (3,14 · 39,98 · 15,0²) = 76,28 / 28 246 = 0,0027 г/мм³ = **2701 кг/м³**

### 2. СКО плотности
σ(ρ̄) = ρ̄·√[(σ(h̄)/h̄)² + 4·(σ(d̄)/d̄)²] = 2701·√[(0,049/39,98)² + 0] = 2701 · 0,001225 = **3,3 кг/м³**

### 3. Случайная погрешность
Δρ_сл = σ(ρ̄)·t = 3,3 · 2,78 = **9,2 кг/м³**

### 4. Систематическая погрешность
Δs(ρ̄) = 1,1·ρ̄·√[(Δs(m)/m)² + (Δs(h)/h̄)² + 4·(Δs(d)/d̄)²]
= 1,1 · 2701 · √[(0,01/19,07)² + (0,1/39,98)² + 4·(0,1/15,0)²]
= 1,1 · 2701 · √[2,75·10⁻⁷ + 6,26·10⁻⁶ + 1,778·10⁻⁴] = 1,1 · 2701 · 0,01357 = **40,3 кг/м³**

### 5. Результирующая погрешность
Δs(ρ̄)/σ(ρ̄) = 40,3 / 3,3 = **12,2 > 8** → **Δ(ρ̄) = Δs(ρ̄) = 40 кг/м³**
δ(ρ̄) = 40/2701 · 100 % = **1,5 %**
